# Code review skill

When reviewing Python changes:

1. Read the changed code and its tests.
2. Look for correctness, error handling, security, and maintainability issues.
3. Prefer concrete findings with file and line references.
4. Run relevant tests when possible.
5. Separate confirmed problems from suggestions.

# Testing skill

When testing this project:

1. Inspect the relevant implementation and existing tests first.
2. Prefer a focused test before the full suite.
3. Treat the process exit code as authoritative.
4. Report failures with the command and useful error output.
5. Do not claim success without an actual passing test result.
